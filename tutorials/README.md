# Netmask OS // Tutorial Pack

33 lessons, written for the tools that ship on this OS. Open with
`netmask-learn` (or Super+F2), read with `less`/`glow`-style pagers.

| Path | Lessons | Theme |
|---|---|---|
| `reversing/` | 01–09 (+06b) | RE fundamentals → VMs, packers, devirtualization |
| `exploiting/` | 01–08 | memory corruption → full exploit workflow |
| `malware/` | 01–07 | triage → ransomware, rootkits, AV evasion |
| `crypto/` | 01–04 | primitives → breaking crypto, side channels, EVM |
| `forensics/` | 01–04 | disk/memory/network/mobile |

## Reading order suggestions

**New to RE:** reversing 01 → 02 → 03 → crackme01 → reversing 07
**Exploit-curious:** exploiting 01 → 02 → 07 → 08 (build the labs!)
**DFIR track:** forensics 01 → 02 → malware 04 → forensics 03
**CTF night:** crypto 02 + RsaCtfTool + sage + the crackme pack

## Ethics reminder (short version)

Analyze your own binaries, CTF targets, authorized engagements and
public training ranges. Every lesson states its scope; respect it.
